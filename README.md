# Пульт X96 — Android + веб-пульт для iPhone

Android-приложение Flutter продолжает пользоваться собственным TLS-протоколом приставки на порту **39678**. В сборке TV Companion **0.3.0** добавлен отдельный веб-пульт для Safari на **8088**. Существующие Flutter-файлы не менялись.

## Как установить веб-пульт с одного телефона

1. Замените файлы в GitHub-репозитории содержимым этого обновлённого ZIP (сохраняя пути). **Не нужно загружать ZIP как один файл репозитория**: GitHub Actions соберёт старый проект, если ZIP останется вложением.
2. Откройте GitHub → **Actions → Build TV Companion APK → Run workflow**. Дождитесь успешной сборки, а затем скачайте **Pult-TV.apk** в **Releases**. Android-смартфон и iPhone используются только для управления; Mac не нужен.
3. Установите обновлённое приложение **Пульт · Приставка** на X96. При несовпадающих подписях прежнего тестового APK Android может потребовать удалить старое приложение приставки. Это обнулит сопряжение и потребует заново включить Accessibility и клавиатуру.
4. На X96 откройте **Пульт · Приставка**. Убедитесь, что служба специальных возможностей включена. На экране будет показана строка `Веб-пульт: http://IP:8088`. При необходимости запишите IP приставки (например, `192.168.1.100`).
5. На iPhone подключитесь к **той же домашней Wi-Fi сети**. В Safari откройте `http://IP-ПРИСТАВКИ:8088` (подставьте фактический адрес), например `http://192.168.1.100:8088`.
6. На приставке нажмите **«ПОКАЗАТЬ КОД НА 2 МИНУТЫ»**. Введите шестизначный PIN в Safari. Браузерная сессия действует пока работает компаньон (тайм-аут неактивности — 12 часов), перезапуск службы потребует новый PIN. Веб-сопряжение **не сбрасывает** существующий Android-токен.
7. В Safari выберите **Поделиться → На экран «Домой» → Открывать как веб-приложение** (если такой переключатель виден). Значок появится на iPhone. Постоянный IP в настройках DHCP роутера нужен, чтобы адрес приставки не менялся.

## Функции

- Назад, Домой, список недавних, управление громкостью и медиавоспроизведением.
- D-pad на основе Accessibility `focusSearch` (работает только в интерфейсах, которые предоставляют навигацию через дерево доступности; для других экранов есть мышь).
- Полноэкранная мышь с одним пальцем, прокрутка двумя пальцами или полосой справа, клик, удержание/перетаскивание.
- Список установленных приложений и запуск из браузера.
- Отправка текста, удаление символа (русский текст работает лучше с клавиатурой «Пульт · ввод с телефона»).
- Просмотр H.264 экрана X96 и тапы/свайпы поверх видео. Для низкой задержки браузер демультиплексирует H.264 и подаёт fMP4 в MediaSource/ManagedMediaSource. На приставке **обязательно включите трансляцию вручную**. Звук не передаётся. Поддержка и задержка видео зависят от прошивки приставки и версии Safari; реальное воспроизведение на iPhone ещё нужно проверить. Для iPhone предпочтительна iOS 17.1 или новее.
- Периодические проверки связи, восстановление браузерного видео после обрыва. Команды нажатия намеренно **не переигрываются автоматически** после тайм-аута, чтобы исключить двойные клики.

## Безопасность и ограничения

**Важное отличие:** Android-клиент продолжает использовать TLS с закреплённым сертификатом. Встроенный веб-пульт пока работает по **незашифрованному HTTP** — поэтому **только домашняя доверенная сеть**, не гостевой/общественный Wi-Fi, не пробрасывайте порт 8088 в интернет и не подключайте к нему публичный туннель. PIN и сессионный cookie могут быть перехвачены устройствами, способными прослушивать локальный трафик. Веб-API ограничен IPv4 LAN, используется одноразовый PIN, `HttpOnly; SameSite=Strict` cookie, проверка Origin/Host и отсутствие внешних ресурсов. «Сбросить доступ телефона» на приставке завершает и браузерные сеансы.

Это **локальный веб-ярлык**, а не полностью офлайн PWA: для service worker и полноценного защищённого PWA потребовался бы доверенный HTTPS-сертификат. Иконка на домашнем экране сама по себе не обеспечивает офлайн-работу.

## Структура изменений

- `tv_companion/app/src/main/java/app/pult/tv/WebRemoteServer.kt` — локальный HTTP-сервер / API / H.264 поток.
- `tv_companion/app/src/main/assets/web/` — интерфейс iPhone, тачпад, JS-видеоплеер, манифест и значок.
- `PairingStore.kt` — независимый от Android-токена PIN вход браузера и сброс сессий.
- `CompanionServer.kt` — запуск/остановка веб-сервера без изменений старого TCP-протокола.
- `TvAccessibilityService.kt` — необязательные кнопки D-pad через Accessibility.
- `MainActivity.kt` — адрес и инструкция в приложении приставки.
- `tv_companion/app/build.gradle.kts` — версия 0.3.0 (3).

## Разработка/проверка

В GitHub Workflow `Build TV Companion APK` собирает APK на Android SDK 34. Для iOS никаких инструментов сборки не требуется. В этом архиве исходный код веб-плеера был проверен на синтаксис Node.js, тестовые fMP4-фрагменты корректно распознаны и декодированы с помощью FFmpeg/ffprobe. **Полная Android-сборка и испытание на настоящем X96/iPhone в этой среде не проводились.**
